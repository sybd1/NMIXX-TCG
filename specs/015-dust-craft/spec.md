## 목표

쓸모없는 중복 카드를 더스트로 바꾸고, 더스트로 원하는 카드를 만들어 수집 막바지의 운 요소를 줄인다.

- 제외: MR·XR·세트 보상 카드 제작(제작 불가), 1장만 가진 카드 분해

## 인수 조건

- **AC-01** Given SR 카드 3장(중복 2장)만 중복 When 공방 › `중복 카드 일괄 분해하기` Then 그 카드가 1장이 되고 더스트가 240(120×2) 늘며 `중복 카드 2장을 분해하여 ✨ 240 더스트를 획득했습니다!`가 보인다
- **AC-02** Given 중복 카드 없음 When 일괄 분해 탭을 본다 Then 버튼이 비활성이고 `분해할 중복 카드가 없습니다`로 표시된다
- **AC-03** Given 더스트 400, 미보유 R 카드 When `원하는 카드 확정 제작`에서 그 카드 제작 Then 더스트 0, 카드 1장이 생기고 `✨ {이름} 제작에 성공했습니다!`
- **AC-04** Given 더스트 399 When R 카드 제작 목록을 본다 Then 제작 버튼이 비활성이다(`CraftingModal.tsx` 362행. `보유한 더스트가 부족합니다.` 알림 코드는 있으나 도달하지 않음)
- **AC-05** Given MR 카드 When 제작 목록을 본다 Then 목록에 없다
