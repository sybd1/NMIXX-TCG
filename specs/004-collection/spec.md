## 1. 문제와 목표

카드가 수백 장 쌓이면 무엇을 가졌고 무엇이 빠졌는지 알기 어렵다. 이 기능 이후 사용자는 도감 탭에서 521종 전체를 보유 여부·팩·멤버·등급으로 거르고 원하는 순서로 정렬해, 남은 카드와 수집률을 한눈에 본다. 컨셉 세트 진행(기능 005)과 XR 해금 진행(기능 006)도 이 탭에서 보인다.

## 2. 범위

- 포함: 전체 카드 목록, 필터 4종, 정렬 6종과 방향, 24장 페이지, 수집 진행률, 카드 상세 열기, 세트 탭 전환, XR 배너
- 제외: 세트 보상 지급 규칙 — 기능 005 / XR 지급 규칙 — 기능 006 / 더스트 공방 — 기능 015(숨김) / 검색어 입력
- 선행 조건: 기능 001

## 3. 사용자 흐름

1. 도감 탭(`COLLECTION`, 모바일 `CARDS`)을 연다. 기본은 "보유 카드 중 높은 등급순, 내림차순"이다.
2. 상단에서 수집 진행률 `COLLECTION PROGRESS {보유} / 521 ({%})`을 본다.
3. 보유 여부·팩·멤버·등급 버튼을 눌러 거른다. 필터를 바꾸면 1페이지로 돌아간다.
4. 정렬 목록과 오름/내림 버튼으로 순서를 바꾼다.
5. 페이지 버튼으로 24장씩 넘긴다. 넘기면 목록 위로 스크롤된다.
6. 카드를 누르면 상세 창이 열린다(기능 001).

## 4. 요구사항과 인수 조건(AC)

### REQ-01: 진행률

- **AC-01** 정상: 진행률은 보유 종류 수 기준이다
  - Given 서로 다른 카드 100종, 그중 한 종은 3장
  - When 도감 탭을 연다
  - Then `COLLECTION PROGRESS 100 / 521 (19%)`가 보인다(중복은 세지 않음, 정수 반올림)

### REQ-02: 필터

필터는 함께 적용된다(AND). 박진영(PARK) 멤버 필터와 XR 등급 필터는 XR을 가진 뒤에만 보인다.

- **AC-02** 정상: 조건이 겹치면 모두 만족하는 카드만 보인다
  - Given 전종 보유(로컬 개발 환경)
  - When 팩 NX-03, 멤버 해원, 등급 SR을 고른다
  - Then NX-03의 해원 SR 카드만 보이고 결과 수가 데이터의 해당 개수와 같다
- **AC-03** 경계: 결과가 없으면 빈 목록이다
  - Given NX-01 선택
  - When 등급 MR을 고른다
  - Then 카드가 0장이고 페이지 버튼이 없다(NX-01에는 MR 카드가 없음)
- **AC-04** 보유 필터
  - Given 일부만 보유
  - When `🔒 못 모은 카드만`을 누른다
  - Then 미보유 카드만 보이고 모두 `🔒 LOCKED` 표시다
- **AC-05** 숨김 필터: XR 전에는 박진영·XR 필터가 없다
  - Given XR 미보유
  - When 멤버·등급 필터를 본다
  - Then `박진영`과 `XR` 버튼이 없다

### REQ-03: 정렬

정렬 옵션: 보유 카드 중 높은 등급순 / 모은 카드 우선 / 못 모은 카드 우선 / 도감 번호순 / 등급순 / 보유 수량순. 각각 오름·내림 전환.

- **AC-06** 정상: 보유 수량순
  - Given 같은 카드를 5장, 3장, 1장 가진 카드가 있음
  - When `🃏 보유 수량순`, `▼ 내림차순`
  - Then 5장 카드가 첫 칸, 그다음 3장, 1장 순이다

### REQ-04: 페이지

- **AC-07** 정상: 24장씩 나뉜다
  - Given 결과 50장
  - When 목록을 본다
  - Then 1페이지 24장, `페이지 1 / 3`, `총 50장 중 1 - 24번째 카드`가 보인다
  - 그리고 3페이지는 2장이다
- **AC-08** 경계: 필터를 바꾸면 1페이지로 돌아간다
  - Given 3페이지
  - When 등급 필터를 바꾼다
  - Then `페이지 1 / …`이 된다

## 5. 화면 상태

| 상태 | 진입 조건 | 보이는 것 | 가능한 행동 |
|---|---|---|---|
| 전체 카드 탭 | 기본 | 진행률, 필터, 정렬, 카드 24장, 페이지 버튼 | 필터·정렬·페이지·상세 |
| 결과 없음 | 필터 결과 0장 | 빈 카드 영역 | 필터 변경 |
| 세트 탭 | `NMIXX 세트 카드 (6종)` 클릭 | 세트별 6장과 보상 버튼 (기능 005) | 보상 받기 |
| XR 배너 | 두 탭 모두 상단 | 해금 진행률, 상태별 문구 (기능 006) | 해금 |

- 주요 문구: `NMIXX COLLECTION ARCHIVE`, `총 {total}장의 NMIXX 공식 카드 중 {owned}종 획득 완료`, `전체 보기`, `🎉 모은 카드만`, `🔒 못 모은 카드만`, `◀ 이전`, `다음 ▶`
- 접근성·반응형: 카드 그리드는 화면 너비에 따라 열 수가 바뀐다. 7페이지 초과면 말줄임 페이지 목록.

## 6. 품질 요구

- 필터·정렬은 클라이언트 메모리에서 계산한다(521장). 한 페이지에 24장만 그려 카드 효과 렌더 부담을 줄인다(v1.5.2).

## 7. 미결 질문

- 알려진 한계: 팩 필터 목록(`PACK_FILTERS`)이 코드에 하드코딩되어 팩을 추가하면 함께 고쳐야 한다(기능 001 plan 3절 절차).
- 알려진 한계: `전체 보기 ({n})` 숫자는 XR을 숨기는 동안에도 XR을 포함한다.
- 알려진 한계: 페이지 이동 시 스크롤 위치가 380px로 하드코딩되어 있다.
- 미사용 코드: 레거시 카드(`ownedLegacyCards`, 항상 빈 배열), 더스트 공방 버튼(주석 처리, 기능 015).
