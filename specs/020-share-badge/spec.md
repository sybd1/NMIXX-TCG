> 작은 기능용 한 장짜리 명세. 계약이 새로 생기거나, 파일이 5개 넘게 바뀌거나, 데이터 구조가 바뀌면 Full로 전환한다.

## 목표

자기 순위와 수집 현황을 이미지·링크로 SNS에 자랑하게 해 새 사용자를 데려온다.

- 제외: 인스타그램 직접 게시(이미지 저장 후 수동 업로드 안내만)

## 인수 조건

- **AC-01** Given 로그인 사용자, 순위 12위/전체 50명 When 랭킹 탭 `내 배지 공유` Then 배지 카드에 닉네임, `TOP 24%`, 보유 카드 수, 수집 달성률, 대표 카드 3장이 보인다
- **AC-02** Given 배지 창 When `이미지 저장` Then `nmixx-tcg-badge-{닉네임}.png`가 내려받아지고 `📸 이미지 저장 완료! …` 알림
- **AC-03** Given 배지 창 When `X 공유` Then 600×450 창에 X(트위터) 작성 화면이 `[NMIXX TCG] 현재 제 랭킹은 …! #NMIXX #엔믹스 #NMIXX_TCG` 문구와 사이트 주소로 열린다
- **AC-04** Given 배지 창 When `링크 복사` Then `https://nmixx-tcg.vercel.app/`이 클립보드에 들어가고 `🔗 링크가 클립보드에 복사되었습니다!`
- **AC-05** Given 게스트 When `내 배지 공유` Then `로그인 후 공유 가능합니다` 안내만 보인다
- **AC-06** Given 카드 이미지 때문에 캔버스 변환 실패 When `이미지 저장` Then `이미지 저장 중 오류가 발생했습니다.`

## 구현 메모

- 바꿀 파일: `src/components/Share/ShareBadgeModal.tsx`(배지는 인라인 스타일, `html-to-image` `toPng` 동적 import, pixelRatio 3) / `src/pages/Ranking/RankingPage.tsx`(순위·대표 카드 계산 후 전달)
- 테스트: 수동. 배포 사이트 로그인 계정으로 AC-01~04, 시크릿 창으로 AC-05
- 알려진 한계: 대표 카드 3장은 기능 010의 정렬 버그 때문에 C·UC가 먼저 뽑힐 수 있다(010 tasks T007). 파일 이름에 닉네임을 그대로 써 특수문자가 있으면 저장 이름이 깨질 수 있다. 1명 중 1위면 `TOP 100%`로 보인다.
