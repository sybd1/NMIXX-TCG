## 1. 문제와 목표

카드를 얻는 순간이 이 게임의 핵심 재미다. 목록에서 결과만 보여 주면 실물 팩을 뜯는 설렘이 없다. 이 기능 이후 사용자는 3D 팩을 골라 직접 찢고, 카드를 한 장씩(또는 한 번에) 뒤집으며, 고등급은 크게 따로 보여 주는 연출을 거쳐 결과 요약을 본다.

## 2. 범위

- 포함: 팩 탭의 팩 선택 캐러셀, 팩별 수집률, 첫 방문 화면, 전체 화면 개봉 단계(입장 → 찢기 → 카드 배치 → 공개 → SSR+ 쇼케이스 → 요약), 같은 팩 다시 열기, 키보드 조작, WebGL이 없을 때 2D 팩, 효과음
- 제외: 추첨·코인 계산 — 기능 002 / 카드 앞면 디자인 — 기능 001 / 이스터에그 우주선 — 기능 019
- 선행 조건: 기능 002

## 3. 사용자 흐름

1. 팩 탭에서 5개 팩이 원형으로 돌아가는 캐러셀을 휠·화살표 버튼·←→ 키·옆 팩 클릭으로 넘긴다. 가운데 팩 아래 팩 이름, 설명, 팩 수집률이 보인다.
2. 가운데 팩을 누르거나 `1팩 개봉`·`5팩 연속`·`10팩 대량`을 누르면 화면이 어두워지고 팩이 들어온다.
3. 팩을 누르거나 Space·Enter를 누르면 팩이 찢어지고(이때 결제·지급, 기능 002) 카드가 뒷면으로 깔린다.
4. 카드를 하나씩 눌러 뒤집거나 `⚡ 카드 모두 공개하기`(Space)로 한 번에 뒤집는다.
5. 모두 뒤집히면 SSR 이상 카드가 있을 때 한 장씩 큰 상세 창으로 보여 준다.
6. 요약 화면에서 획득 수, 등급별 개수를 보고 `🔁 다시 열기`, 다른 수량 구매, `메인 홈` 중 하나를 고른다.

## 4. 요구사항과 인수 조건(AC)

### REQ-01: 팩 선택

- **AC-01** 정상: 팩을 넘기면 정보가 바뀐다
  - Given 팩 탭, 가운데 NX-01
  - When → 키를 누른다
  - Then 가운데가 NX-02로 바뀌고 팩 이름·설명·`수집률 X%`·`보유/전체장`이 NX-02 값으로 바뀐다
  - 그리고 NX-05에서 →를 누르면 NX-01로 돌아온다(무한 순환)
- **AC-02** 첫 방문: 처음 온 사용자에게 안내 화면이 보인다
  - Given `isFirstVisit`가 true인 상태
  - When 팩 탭을 연다
  - Then `NMIXX TCG`와 `[ OPEN YOUR FIRST PACK ]` 버튼이 보이고, 누르면 안내가 사라지며 1팩 개봉이 시작된다

### REQ-02: 개봉 단계

- **AC-03** 정상: 찢으면 카드가 깔리고 진행 수가 보인다
  - Given 1팩 개봉 화면
  - When 팩을 누른다
  - Then 0.7초 안에 뒷면 카드 5장이 깔리고 `카드를 터치하여 공개하세요 (0/5종)`이 보인다
- **AC-04** 정상: 모두 공개
  - Given 카드가 깔린 상태
  - When Space를 누른다
  - Then 모든 카드가 앞면으로 뒤집히고, SSR 이상이 없으면 0.4초 뒤 요약 화면이 나온다
- **AC-05** 정상: 고등급 쇼케이스
  - Given 공개된 카드 중 SSR 이상이 2장
  - When 마지막 카드가 뒤집힌다
  - Then 그 2장의 상세 창이 차례로 열리고, 닫으면 다음 장, 마지막 장을 닫으면 요약이 나온다
- **AC-06** 정리: 같은 카드는 한 칸으로 합친다
  - Given 10팩에서 같은 카드가 3장 나옴
  - When 카드가 깔린다
  - Then 그 카드는 한 칸에 `x3`으로 보이고, 새 카드(`NEW`)가 앞, 그다음 등급 순으로 정렬된다
  - 그리고 요약에 `NMIXX 10팩 (50장 획득 • {합친 종류}종 정리) 개봉 완료!`가 보인다
- **AC-07** 연타 방지: 키를 꾹 눌러도 단계가 건너뛰어지지 않는다
  - Given 개봉 화면
  - When Space를 꾹 누른다(키 반복)
  - Then 반복 입력은 무시되고, 한 번 누를 때마다 한 단계씩만 진행된다(입력 간 250ms, 단계 진입 후 350ms 대기)

### REQ-03: 다시 열기와 종료

- **AC-08** 정상: 같은 팩을 바로 다시 연다
  - Given 1팩 요약 화면, 코인 충분
  - When `🔁 1팩 다시 열기 (3,800 N)` 또는 Space를 누른다
  - Then 같은 팩의 새 개봉 화면이 시작되고, 팩을 찢으면 코인이 3,800 줄고 카드가 지급된다
- **AC-09** 입력 오류: 코인이 모자라면 다시 열 수 없다
  - Given 요약 화면, 코인 < 해당 가격
  - When Space를 누른다
  - Then 아무 일도 일어나지 않는다
- **AC-10** 종료: 요약에서 나가면 팩 탭으로 돌아온다
  - Given 요약 화면
  - When `메인 홈`, ESC, 브라우저 뒤로가기 중 하나를 누른다
  - Then 개봉 화면이 닫히고 팩 탭이 보이며 다음 구매가 가능하다

### REQ-04: 3D 대체

- **AC-11** 실패·복구: WebGL이 없으면 2D 팩으로 연다
  - Given WebGL 렌더러 생성이 예외를 던지는 브라우저
  - When 팩을 개봉한다
  - Then 개봉 화면의 팩이 평면 이미지(포일 질감 오버레이)로 보이고 개봉 흐름은 같다
  - (WebGL 지원 여부를 미리 검사하지 않는다. `src/utils/webgl.ts`의 `isWebGLSupported`는 호출되지 않는다)

## 5. 화면 상태

| 상태 | 진입 조건 | 보이는 것 | 가능한 행동 |
|---|---|---|---|
| 첫 방문 | `isFirstVisit` | 환영 문구, `[ OPEN YOUR FIRST PACK ]` | 첫 개봉 |
| 팩 선택 | 팩 탭 | 3D 팩 캐러셀, 수집률, 구매 버튼 3개, 천장 게이지, `🖱️ 마우스 휠 스크롤로 팩 무한 순환 전환` | 넘기기, 구매 |
| 어두워짐 | 구매 직후 | 배경 어두워짐 (0.3초) | 없음 |
| 팩 입장 | DIM 후 | 팩, `👆 카드팩을 터치하여 개봉하기! (Space)`, 팩 수집률·천장 남은 횟수 | 찢기, ESC |
| 카드 배치 | 찢은 뒤 | 뒷면 카드, `카드를 터치하여 공개하세요 (n/m종)`, `⚡ 카드 모두 공개하기` | 한 장·전체 공개, 공개된 카드 상세 |
| 쇼케이스 | 모두 공개 + SSR 이상 | SSR 이상 카드 상세 창 연속 | 닫기 |
| 요약 | 쇼케이스 끝 또는 SSR 미만 | 완료 문구, 등급별 `MR xN` 칩(XR 제외), 다시 열기·1/5/10팩·`메인 홈` | 다시 열기, 나가기 |

- 주요 문구: 위 표와 같음. 닫기 버튼은 요약 단계에서 `메인으로 (ESC)`, 그 외 단계에서 `메인으로`(작은 화면에서는 아이콘만).
- 접근성·반응형: 10종 초과면 작은 카드. 모바일 너비(<640px)에서 캐러셀 간격 125px, 그 이상 190px. Space·Enter·ESC·←→ 키 지원.

## 6. 품질 요구

- 카드 이미지는 개봉 화면이 열릴 때 미리 디코딩(`img.decode()`)해 뒤집을 때 깜박이지 않게 한다.
- 3D 팩은 화면에 보이지 않거나 탭이 숨겨지면 렌더 루프를 멈춘다(IntersectionObserver, visibilitychange).
