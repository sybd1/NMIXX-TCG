# Spec 007: 로그인(구글·카카오·게스트)

- 상태: Implementing  <!-- 코드 배포됨, 검증 기록 미완 -->
- 최종 수정일: 2026-11-10
- 제품 문서: [docs/product.md](../../docs/product.md) 기능 007
- 디자인 자료: 없음 — 5절 표로 대신함

## 1. 문제와 목표

로그인이 없으면 진행이 브라우저 하나에 묶이고 랭킹도 만들 수 없다. 한국 팬이 가입 절차 없이 쓰도록, 이미 가진 구글·카카오 계정으로 한 번에 로그인하게 한다. 로그인하지 않아도 게스트로 바로 놀 수 있지만 진행은 남지 않는다(DEC-009).

## 2. 범위

- 포함: 로그인 창, 구글 팝업 로그인, 카카오 SDK 로그인, 게스트 시작, 최초 가입 시 닉네임 지정(선택), 기존 닉네임·아바타 복원, 세션 유지(새로고침), 로그아웃, 운영자 계정 식별(DEC-012)
- 제외: 닉네임 변경 — 기능 013 / 탈퇴 — 기능 014 / 저장·동기화 — 기능 008 / 이메일·비밀번호 가입 / 한 계정 한 기기 강제(DEC-010 → DEC-011로 폐기)
- 선행 조건: Firebase 프로젝트 `nmixx-tcg`, Kakao 앱 JS 키, Firebase Authorized domains에 배포 도메인 등록

## 3. 사용자 흐름

1. 헤더 오른쪽 `로그인`을 누르면 로그인 창이 열린다.
2. (선택) 닉네임을 입력한다(최대 12자). 비우면 자동 생성된다.
3. `Google 계정으로 시작` 또는 `카카오 계정으로 시작`을 누르면 각 서비스 팝업이 뜬다. 버튼은 `… 연결 중...`으로 바뀐다.
4. 성공하면 창이 닫히고 헤더에 최애 멤버 이모지와 닉네임이 보인다. 클라우드 진행이 불러와진다(기능 008).
5. 실패하면 창 안에 오류 문구가 보이고 다시 시도할 수 있다.
6. `로그인 없이 게스트로 시작하기`를 누르면 바로 게임을 한다.
7. 프로필 창의 `로그아웃`으로 나간다.

## 4. 요구사항과 인수 조건(AC)

### REQ-01: 구글 로그인

계정 ID는 `goog_<Firebase UID>`. 이미 Firestore에 프로필이 있으면 그 닉네임·아바타를 쓴다. 처음이면 입력한 닉네임 → 구글 이름 → `엔써_<UID 앞 5자>` 순으로 정하고, 다른 사람이 쓰는 이름이면(입력하지 않은 경우만) `_<UID 앞 4자>`를 붙인다.

- **AC-01** 정상: 처음 로그인하면 계정이 만들어진다
  - Given Firestore에 문서가 없는 구글 계정
  - When 닉네임 칸을 비우고 `Google 계정으로 시작` → 계정 선택
  - Then 헤더에 구글 이름이 보이고 `nmixx_tcg_users/goog_<uid>`에 `displayName`, `nickname`, `email`, `provider: "google"`, `sessionId`가 생긴다
- **AC-02** 정상: 다시 로그인하면 바꾼 닉네임이 유지된다
  - Given 닉네임을 "해원최고"로 바꾼 계정
  - When 로그아웃 후 다시 구글로 로그인한다
  - Then 헤더에 "해원최고"가 보인다
- **AC-03** 실패·복구: 팝업을 닫거나 차단되면 안내한다
  - Given 로그인 창
  - When 구글 팝업을 그냥 닫는다
  - Then `로그인 팝업이 닫혔거나 브라우저 보안 정책에 의해 차단되었습니다. 팝업 차단을 해제하거나 다시 시도해 주세요.`가 보이고 버튼이 다시 눌린다
- **AC-04** 실패: 허용되지 않은 도메인
  - Given Authorized domains에 없는 주소 [확인 필요: 콘솔 설정 — README는 `127.0.0.1`이 등록되어 있지 않다고 적음]
  - When 구글 로그인
  - Then `이 주소(…)는 Firebase 로그인 허용 목록에 없습니다.`로 시작하는 문구가 보인다

### REQ-02: 카카오 로그인

계정 ID는 `kakao_<카카오 회원번호>`. 같은 기기에 같은 카카오 계정 세션이 있으면 그 닉네임을 먼저 쓰고, 없으면 Firestore 프로필, 그것도 없으면 입력값 → 카카오 닉네임 → `카카오_엔써_<앞 4자>` 순이다.

- **AC-05** 정상: 카카오로 로그인한다
  - Given 카카오 계정
  - When `카카오 계정으로 시작` → 동의
  - Then 헤더에 닉네임이 보이고 `nmixx_tcg_users/kakao_<id>` 문서에 `provider: "kakao"`가 있다
- **AC-06** 실패·복구: 카카오 팝업 실패
  - Given 로그인 창
  - When 카카오 팝업에서 취소한다
  - Then `카카오 로그인 처리 중 문제가 발생했습니다.`(또는 SDK 오류 문구)가 보이고 다시 시도할 수 있다

### REQ-03: 게스트와 세션

- **AC-07** 정상: 게스트로 시작
  - Given 로그인 창
  - When `로그인 없이 게스트로 시작하기`
  - Then 창이 닫히고 코인 1,000,000으로 플레이할 수 있으며, 랭킹 등록·클라우드 저장은 되지 않는다
- **AC-08** 정상: 새로고침해도 로그인이 유지된다
  - Given 구글 또는 카카오로 로그인한 상태
  - When 페이지를 새로고침한다
  - Then 로그인 창 없이 같은 계정으로 보인다(`localStorage['nmixx_tcg_auth_session_v1']`)
- **AC-09** 정상: 로그아웃
  - Given 로그인 상태
  - When 프로필 창에서 `로그아웃`
  - Then 헤더가 `로그인` 버튼으로 바뀌고 팩 탭으로 이동하며 게스트 초기 상태가 된다

### REQ-04: 운영자 계정

- **AC-10** 운영자 이메일로 로그인하면 이름이 `운영자`로 고정된다 (DEC-012)
  - Given 운영자 이메일의 구글 계정
  - When 로그인한다
  - Then 헤더 이름이 `운영자`이고 랭킹에 나오지 않는다
  - (DEC-012의 "1억 N·전종 보유로 시작"은 로그인 순서 때문에 실제로는 거의 적용되지 않는다. specs/008 plan 7절)

## 5. 화면 상태

| 상태 | 진입 조건 | 보이는 것 | 가능한 행동 |
|---|---|---|---|
| 로그아웃 | 세션 없음 | 헤더 `로그인` | 로그인 창 열기 |
| 로그인 창 | `로그인` 클릭 | `NMIXX TCG 간편 회원가입`, 닉네임 입력, 버튼 3개 | 로그인, 게스트, 닫기 |
| 연결 중 | 버튼 클릭 후 | `Google 계정 연결 중...` / `카카오 계정 연결 중...` | 대기 |
| 오류 | 로그인 실패 | 창 안 오류 문구 | 재시도 |
| 로그인됨 | 성공 | 헤더 멤버 이모지 + 닉네임 | 프로필 창 |

- 주요 문구: 위 표와 AC 문구
- 접근성·반응형: 데스크톱·모바일 동일 창. 닉네임 입력 `maxLength 12`.

## 6. 품질 요구

- 구글 팝업을 위해 응답 헤더 `Cross-Origin-Opener-Policy: same-origin-allow-popups`가 필요하다(DEC-021, `vercel.json`·`vite.config.ts`).
- 세션 객체에는 비밀번호·토큰을 저장하지 않는다. `securityHash`는 세션 필드의 SHA-256(위변조 감지용 표시)이며 서버 검증은 없다.

- [확인 필요: Kakao SDK가 없거나 초기화에 실패하면 `loginWithKakao`가 무작위 ID로 **로컬 전용 카카오 계정**을 만든다(`authService.ts` 337행 이후). 같은 사람이 다시 로그인하면 다른 계정이 된다. 이 대체 동작을 유지할지, 오류로 바꿀지 — 구현 막음: 아니오]
- 알려진 한계: 허용되지 않은 도메인 오류 문구가 `http://localhost:5173`을 안내하지만 개발 서버 포트는 3000이다(`vite.config.ts`).
- 알려진 한계: 게스트 로그인 실패 시 오류를 잡지 않아 아무 표시가 없다(`AuthModal.tsx`). 최초 가입 닉네임은 이 창에서 길이·금지어 검사를 하지 않는다(기능 013과 다름).
- 알려진 한계: 로그인 창의 보안 안내 문구("256-bit SHA-256 & OAuth 2.0 보안 암호화", "100% 원천 차단")는 실제 보호 수준보다 과장되어 있다(DEC-001).
