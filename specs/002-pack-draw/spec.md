- 상태: Implementing  <!-- 코드 배포됨, 검증 기록 일부 완료 -->
- 최종 수정일: 2026-11-10
- 제품 문서: [docs/product.md](../../docs/product.md) 기능 002
- 디자인 자료: 없음 — 버튼 배치는 기능 003 화면 상태 표

## 1. 문제와 목표

사용자는 코인으로 팩을 사서 카드를 얻는다. 확률은 공개되어야 하고 결과는 공정해야 하며, 운이 아주 나빠도 고등급을 영원히 못 얻는 일은 없어야 한다. 이 기능은 가격, 한 팩의 구성, 등급 확률, 천장 규칙과 결과를 컬렉션에 반영하는 거래를 정의한다.

## 2. 범위

- 포함: 1·5·10팩 가격, 팩당 5장, 등급 추첨, 팩 풀에서 카드 선택, 천장(50팩), 코인 차감과 카드 지급을 한 번에 반영, 개봉 기록 50건
- 제외: 개봉 연출 — 기능 003 / 확률표 화면 — 기능 021 / 고등급 전광판 — 기능 011 / 미보유 우선 지급(스마트 천장) — 구현하지 않음(DEC-005)
- 선행 조건: 기능 001

## 3. 사용자 흐름

1. 팩 탭에서 팩을 고르고 `1팩 개봉`·`5팩 연속`·`10팩 대량` 중 하나를 누른다.
2. 코인이 모자라면 버튼이 비활성이라 누를 수 없다.
3. 개봉 화면이 열리고, 팩을 찢는 순간 코인이 차감되고 카드가 도감에 들어간다(기능 003).
4. 천장 게이지(`n / 50`)가 갱신된다.
5. 개봉 화면을 팩을 찢기 전에 닫으면 코인도 카드도 변하지 않는다.

## 4. 요구사항과 인수 조건(AC)

### REQ-01: 가격과 구성

1팩 3,800 N(5장), 5팩 17,100 N(25장, 10% 할인), 10팩 34,200 N(50장, 10% 할인). 원본은 `GAME_CONFIG`.

- **AC-01** 정상: 구매하면 정확히 차감되고 장수만큼 들어온다
  - Given 코인 1,000,000, 천장 0
  - When NX-02 10팩을 사서 팩을 찢는다
  - Then 코인이 965,800이 되고, 도감 보유 수 합계가 50 늘고, 누적 개봉 팩 수가 10 늘어난다
- **AC-02** 입력 오류: 코인이 모자라면 살 수 없다
  - Given 코인 17,000
  - When 팩 탭을 본다
  - Then `5팩 연속`·`10팩 대량` 버튼이 비활성이고 `1팩 개봉`만 누를 수 있다
  - 그리고 비활성 버튼을 눌러도 개봉 화면이 열리지 않고 코인이 그대로다
- **AC-03** 실패·복구: 찢기 전에 나가면 아무 것도 바뀌지 않는다
  - Given 1팩 구매 버튼을 눌러 개봉 화면이 열린 상태
  - When 팩을 찢기 전에 ESC 또는 뒤로가기를 누른다
  - Then 코인·도감·천장 게이지가 구매 전과 같다

### REQ-02: 등급 확률

팩의 5장은 각각 독립적으로 등급을 뽑는다(C 51.66 / UC 30 / R 15 / SR 2.5 / SSR 0.45 / UR 0.25 / LR 0.12 / MR 0.02 %). XR은 나오지 않는다(DEC-006). 가장 높은 등급 카드가 마지막(5번째)에 온다.

- **AC-04** 정상: 대량 추첨 비율이 공시 확률과 맞다
  - Given 일반 추첨 100만 회
  - When 등급별 비율을 센다
  - Then 각 등급 비율이 공시 확률과 ±0.1%p 이내로 같고 XR은 0회다
- **AC-05** 정상: 팩 안 카드는 등급 오름차순이다
  - Given 아무 팩
  - When 5장을 뽑는다
  - Then 5번째 카드의 등급이 가장 높거나 같다

### REQ-03: 팩 풀

카드는 고른 팩(`packId`)의 같은 등급 카드 중에서 무작위로 뽑는다. 그 팩에 해당 등급 카드가 없으면 전체 팩의 같은 등급에서 뽑는다.

- **AC-06** 정상: 팩에 있는 등급이면 그 팩 카드만 나온다
  - Given NX-03 팩
  - When 5만 팩을 뽑는다
  - Then 모든 카드의 `packId`가 `op03`이다
- **AC-07** 경계: 팩에 없는 등급이 나오면 다른 팩 카드가 나온다
  - Given NX-01 팩(LR·MR 카드 없음)
  - When LR 등급이 뽑힌다
  - Then NX-02~NX-05의 LR 카드 중 하나가 지급된다

### REQ-04: 천장

SSR 이상 없이 49팩을 연 상태에서 여는 다음 팩(50번째)의 5번째 카드는 SSR 70 / UR 20 / LR 8 / MR 2 %로 뽑는다. 팩에 SSR 이상이 있으면 게이지를 0으로, 없으면 1 올린다(DEC-005).

- **AC-08** 정상: 50번째 팩은 SSR 이상을 보장한다
  - Given 천장 게이지 49
  - When 팩 하나를 연다
  - Then 그 팩에 SSR 이상이 있고 게이지가 0이 된다
- **AC-09** 경계: 49번째 팩까지는 보장하지 않는다
  - Given 천장 게이지 48
  - When 팩 하나를 연다
  - Then 천장 규칙이 적용되지 않는다(일반 확률)
- **AC-10** 정상: 천장 추첨 비율
  - Given 천장 추첨 20만 회
  - When 등급별 비율을 센다
  - Then SSR 70 / UR 20 / LR 8 / MR 2 %에 ±0.5%p 이내다
- **AC-11** 연속 구매: 10팩 안에서도 천장이 이어진다
  - Given 천장 게이지 45
  - When 10팩을 산다
  - Then 앞 팩의 결과로 갱신된 게이지가 다음 팩에 쓰이고, 5번째 팩(게이지 49 시점)까지 SSR 이상이 없었다면 그 팩에서 보장된다

### REQ-05: 중복 실행 방지

- **AC-12** 연타: 개봉이 진행 중이면 다시 구매되지 않는다
  - Given 개봉 화면이 열려 있는 상태
  - When 스페이스·Enter를 연타하거나 꾹 누른다
  - Then 코인 차감과 카드 지급은 한 번만 일어난다

## 5. 화면 상태

화면은 기능 003(팩 선택·개봉)과 기능 021(확률표)에 있다. 이 기능 고유의 표시는 천장 게이지다.

| 상태 | 진입 조건 | 보이는 것 | 가능한 행동 |
|---|---|---|---|
| 게이지 | 항상 | `천장 보장 (50팩 시 SSR+ 확정)`, `{pity} / 50` 막대 | - |
| 개봉 중 게이지 | 개봉 화면 | `확정까지 N회 남음` | - |

## 6. 품질 요구

- 추첨은 정수 난수(`Math.floor(Math.random() * 10000)`)로 해 부동소수점 누적 오차가 없게 한다(DEC-003).
- 추첨은 클라이언트에서 하므로 조작을 막을 수 없다(DEC-001). 서버 검증은 범위 밖이다.
