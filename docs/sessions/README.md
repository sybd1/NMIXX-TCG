# 🧩 NMIXX TCG 프로젝트 개발 세션 분할 가이드 (README)

이 가이드는 프로젝트 개발 시 AI 어시스턴트와의 대화 컨텍스트(토큰)를 극도로 아끼고, 특정 코드 파일만 타겟팅하여 버그를 줄이며 효율적으로 작업할 수 있도록 설계된 분할 문서입니다.

## 💡 진행 방법

1. 새로운 기능을 개발하거나 리팩토링할 때, 이 폴더(`docs/sessions/`) 내에 정의된 해당하는 세션 문서(`session*.md`)를 엽니다.
2. 문서 내의 **[프롬프트 복사용 템플릿]** 박스 전체를 복사합니다.
3. Antigravity 2.0에서 **[New Conversation (새 대화)]** 버튼을 누르거나 채팅창에 `/fork`를 입력하여 깨끗한 상태의 새 방을 엽니다.
4. 복사한 내용을 붙여넣고 개발을 시작합니다.
