# 🧩 세션 4: 카드 필터링 및 대량 카드 스크롤 성능 최적화

이 세션은 수백 장의 대량 카드가 도감 뷰포트에 한꺼번에 렌더링될 때 발생하는 웹 브라우저 랙과 스크롤 성능 저하 문제를 최적화합니다.

## 🎯 주요 목표 및 수정 범위
* **수정 파일**:
  - `src/pages/Collection/CollectionPage.tsx`
  - `src/components/Card/CardVisual.tsx`
* **개발 세부 요건**:
  - 멤버별(릴리~규진) 필터 외에 희귀도 등급별 필터링 기능 강화 및 다중 필터(예: 해원 + UR 등급) 다중 교차 선택 기능 구현.
  - 도감 스크롤 시 화면 바깥에 있는 카드는 브라우저 돔(DOM)에서 언마운트되도록 레이지 로딩(Lazy Loading) 또는 가상 스크롤(Virtual List) 최적화 적용.
  - 카드 리스트 렌더링 시 불필요한 React 리렌더링 제거 (`React.memo` 활용).
