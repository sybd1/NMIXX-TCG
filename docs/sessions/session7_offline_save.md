# 🧩 세션 7: 클라우드 오프라인 백업 버퍼 및 자동 동기화

이 세션은 온라인 플레이 중 발생할 수 있는 네트워크 끊김 현상 하에서 유저의 플레이 데이터를 보존하고, 재연결 시 안전하게 저장하는 싱크 로직을 고도화합니다.

## 🎯 주요 목표 및 수정 범위
* **수정 파일**:
  - `src/services/cloudSyncService.ts`
  - `src/services/storageService.ts`
* **개발 세부 요건**:
  - 서버 저장이 에러로 실패할 경우 로컬 스토리지(`localStorage` 또는 `IndexedDB`)의 별도 '오프라인 백업 버퍼'에 상태를 임시로 쓰기 보존.
  - 브라우저의 `navigator.onLine` 상태 감지 및 `online` 복구 이벤트 발생 시 로컬 버퍼에 쌓여있던 데이터를 Firestore 서버 데이터와 지능적으로 병합(Merge)하여 밀어내기.
  - 데이터 병합 시 유저의 재화가 중복 지급되거나 손실되는 비동기 레이스 컨디션 차단.
