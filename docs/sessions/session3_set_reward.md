# 🧩 세션 3: 세트 보상 UI 및 등급 뱃지 디자인 가공

이 세션은 세트 카드 수집률을 한눈에 보고 보상을 획득하는 수집 화면의 UI 보더 및 불필요한 라인을 정리하고, 획득 완료 처리 뷰를 정교화합니다.

## 🎯 주요 목표 및 수정 범위
* **수정 파일**:
  - `src/pages/Collection/CollectionPage.tsx`
  - `src/data/card-data/sets.json`
* **개발 세부 요건**:
  - 세트 목록의 복잡한 그라데이션 보더 및 번잡한 라인을 제거하고 플랫하고 고급스러운 모던 다크 디자인으로 통합.
  - 세트 완성으로 이미 보상을 수령한 세트는 '수령 완료' 상태의 비활성화(Dimmed) 뷰와 체크 아이콘 처리.
  - 팩 수집 완성 뱃지 디자인을 NX-01~NX-05 번호 순서에 맞게 순차 정렬하고 타이틀 폰트 비율 수정.
