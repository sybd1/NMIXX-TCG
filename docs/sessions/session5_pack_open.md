# 🧩 세션 5: 부스터 팩 오프닝 3D/글로우 이펙트 연출

이 세션은 부스터 팩 개봉 시의 시각적 즐거움을 배가하기 위해 카드 드래그 물리 반응 및 최고 등급 획득 글로우 이펙트를 정교화합니다.

## 🎯 주요 목표 및 수정 범위
* **수정 파일**:
  - `src/components/Pack/PackOpeningSequence.tsx`
  - `src/components/Card/CardVisual.tsx`
* **개발 세부 요건**:
  - 마우스 무브 / 터치 스와이프 움직임에 민감하게 반응하여 카드가 휘어지고 빛이 반사되는 CSS 3D Transform 틸트(Tilt) 연출 세분화.
  - LR 및 MR 등 초고등급 카드가 등장할 때 카드 테두리에 무지개 및 신비로운 특수 파티클 아우라(Aura) 연출 구현.
  - 전체 화면 연출 중 프레임 저하(Lag) 방지를 위한 GPU 가속 및 CSS 하드웨어 가속 최적화.
