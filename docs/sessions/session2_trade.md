# 🧩 세션 2: 1:1 유저 카드 거래소 시스템 최적화

이 세션은 중복 카드를 교환하는 1:1 유저 카드 거래소 탭의 등록 및 교환 완료 흐름을 정교화하고 트랜잭션 예외 처리를 최적화합니다.

## 🎯 주요 목표 및 수정 범위
* **수정 파일**:
  - `src/components/Multiplayer/CardTradeModal.tsx`
  - `src/services/multiplayerService.ts`
* **개발 세부 요건**:
  - 거래 게시글(`CardTradeListing` 스키마) 등록 시, 이미 판매 등록한 카드 유효성 및 보유 수량 유효성 재검토.
  - 판매자 아바타 클릭 시 거래 정보 팝업과 연결.
  - 거래 수락(교환 진행) 시, Firestore 트랜잭션 처리를 고도화하여 양쪽 유저의 보유 카드가 원자적으로 교환(Atomic Swap)되도록 연동.
