# 🧩 세션 8: 배포용 데이터 정합성 자동화 검증 가드

이 세션은 빌드 타임에 이미지의 실존 여부 및 대소문자 매칭을 검증하는 Node.js 스크립트를 확장하여 더 정교한 정적 리소스 무결성 테스트 환경을 구축합니다.

## 🎯 주요 목표 및 수정 범위
* **수정 파일**:
  - `scripts/verify_images.cjs`
  - `package.json`
* **개발 세부 요건**:
  - 각 팩별 JSON 데이터(`src/data/card-data/*.json`) 내의 모든 `image` 키에 매핑된 경로명 대소문자를 검증할 뿐 아니라, `id` 중복 여부 및 세트 카드(`sets.json`) 구성원 매칭 유효성을 검증하는 정적 스크립트 작성.
  - 빌드 전 컴파일 타임에 모든 JSON 데이터 규격의 깨짐이나 속성 유실을 방지하는 JSON Schema 유효성 자동 린터 추가.
  - 문제 발생 시 터미널 상에 명확한 줄 번호와 에러가 발생한 카드 파일 경로를 출력하도록 개편.
