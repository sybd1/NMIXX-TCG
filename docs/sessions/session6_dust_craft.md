# 🧩 세션 6: 크래프팅 더스트 분해 및 카드 제작 모달

이 세션은 남는 카드를 갈아 '더스트'를 얻고, 원하는 멤버 카드를 골라 제작할 수 있는 정교한 인게임 크래프팅 모달을 완성합니다.

## 🎯 주요 목표 및 수정 범위
* **수정 파일**:
  - `src/hooks/useGameState.ts`
  - `src/components/Shop/CraftingModal.tsx` (없을 시 신규 생성)
* **개발 세부 요건**:
  - 보유 중인 중복 카드 일괄 분해 시 등급별 더스트 획득 연산 설계 및 UI 연출.
  - 더스트를 소비하여 잠겨있는 특정 카드를 확정적으로 제작(Craft)하는 비즈니스 로직 작성. (세트 보상 카드 및 XR 제외 잠금 처리 적용)
  - UI에 더스트 보유량 실시간 갱신 및 제작 완료 연출 추가.
